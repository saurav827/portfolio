Fake News Detection System

AI / Machine Learning NLP Pipeline Production Deployment

📌 Project Overview

The Fake News Detection System is a multilingual artificial intelligence platform designed to classify article authenticity. In an era where misinformation spreads rapidly, this platform leverages state-of-the-art NLP algorithms and machine learning classification paradigms to evaluate textual inputs and verify truth vectors.

⚙️ The Problem

Online news distribution channels suffer from malicious article replication and fabrication, which misleads audiences. Manual moderation is slow and struggles with multi-language texts. There is a critical requirement for a lightweight, automated classifier that outputs high-probability indicators of article reliability in real-time.

🛠️ Architecture & Solution

I constructed a machine learning pipeline that preprocesses data (removing stopwords, tokenization, stemming, TF-IDF vectorization) and classifies it using logistic regression and ensemble models. The backend is powered by FastAPI, rendering predictions through a clean web dashboard built on Streamlit. User queries and verification results are cached inside a SQLite dataset.

🚀 Tech Stack Used

Python FastAPI Streamlit Scikit-Learn Natural Language Processing (NLP) SQLite
