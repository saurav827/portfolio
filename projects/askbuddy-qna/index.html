AskBuddy - AI QNA Bot

Generative AI Question Answering LLM

📌 Overview

AskBuddy is an AI-powered Question Answering chatbot designed to provide real-time, accurate answers to user queries. Built using a modern tech stack, it leverages the capabilities of Large Language Models (LLMs) to understand context, extract relevant information, and generate human-like responses seamlessly.

✨ Features

  • Real-time Inference: Rapid question answering capabilities powered by Google Gemini.
  • Conversational Context: Maintains conversational memory using LangChain.
  • User-Friendly Interface: Clean and interactive UI built efficiently with Streamlit.
  • Highly Scalable: Modular pipeline architecture ready for integration with various data sources.

🚀 Tech Stack Used

Python Streamlit LangChain Google Gemini API
